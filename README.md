## 🎯 Skill Set

### UI/UX Development
Building user interfaces that are friendly, simple, useful, and scalable. Focus on intuitive design patterns and consistent user experiences across all devices and platforms.

### Accessibility
WCAG 2.1 AA/AAA compliance, semantic HTML, ARIA attributes, keyboard navigation, screen reader optimization, color contrast analysis, focus management, and accessible forms.

### Performance Optimization
Core Web Vitals optimization — LCP, FID, CLS, TTFB, and INP. Code splitting, lazy loading, image optimization, caching strategies, and bundle size reduction.

### Web Discoverability
SEO, PPC integration, GEO (Generative Engine Optimization), and AEO (Answer Engine Optimization). Structured data, meta optimization, sitemap management, and Search Console analysis.

### Security
OWASP Top 10 awareness, XSS/CSRF prevention, Content Security Policy, secure authentication flows, input sanitization, HTTPS enforcement, and dependency vulnerability scanning.

### Audits
Comprehensive audits covering accessibility, performance, SEO, and security using Lighthouse, axe DevTools, WebPageTest, GTmetrix, and custom audit tooling.
